# 묘연 사주 X MBTI

> 오늘, 나에 대해 얼마나 알고 있나요?

사주, MBTI, 혈액형 세 가지 관점으로 나를 읽어 주는 모바일 웹앱이에요. 두 토끼 점술가가 생년월일시를 바탕으로 사주 원국과 오행, 인복, 희귀도, 연애·대인관계 성향을 풀어 주고, 함께 온 사람과의 궁합도 봐 줘요.

made by yena choi

## 기능

- **홈**: 오늘의 일진과 운세, 추천 콘텐츠
- **단계별 입력**: 이름·성별 → 생년월일·시간 → MBTI → 혈액형 (모르면 건너뛰기)
- **나의 종합 분석**: 타고난 기질, MBTI 성격 특징, 혈액형 이야기, 세 관점의 공통점과 차이, 연애·대인관계 성향
- **둘이 보는 궁합**: 서로의 입장(천을귀인, 십신), 사주·MBTI·혈액형 궁합 점수, 총평과 조언
- **9:16 결과 이미지 저장** (1080×1920, 묘연 로고와 made by yena choi 포함)
- 홈 화면에 추가하면 앱처럼 실행 (PWA manifest 포함)

## 배포 (GitHub Pages)

1. 이 폴더의 파일을 저장소 루트에 그대로 올려요.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 선택하고 저장해요.
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열려요.

빌드 과정은 없어요. `index.html` 하나에 화면과 계산 로직이 모두 들어 있고, 글꼴(Google Fonts)과 이미지 저장 라이브러리(html2canvas)만 CDN에서 불러와요.

## 파일 구성

```
index.html             앱 전체 (HTML·CSS·JS, 토끼 이미지 내장)
manifest.webmanifest   홈 화면 추가용 앱 정보
icons/                 앱 아이콘 (512, 192, 180, 32px)
.nojekyll              GitHub Pages 처리 방지용 빈 파일
```

## 계산 기준

- 양력 생일 기준, 절기는 태양 황경으로 계산해요.
- 시주는 서울 진태양시(−32분)로 보정하고, 1987–88년 서머타임을 반영해요.
- 인복·희귀도·궁합 점수와 혈액형 풀이는 명리 규칙을 바탕으로 만든 재미용 지표예요.
